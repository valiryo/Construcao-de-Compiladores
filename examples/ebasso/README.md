# Exemplos de Enio Basso

Os sete arquivos `.cob` são cópias integrais de [ebasso/cobol-exemplos](https://github.com/ebasso/cobol-exemplos/tree/dbe15b74769c994ceda82b48b2640fb208907d3c), commit `dbe15b74769c994ceda82b48b2640fb208907d3c`. Copyright (c) 2018 Enio Basso. Consulte a [licença MIT original](LICENSE).

O corpus exercita o lexer de formato fixo. A suíte confere posições, máscaras PIC, continuações e tokenização pela CLI.

```bash
python -m cobol_lexer examples/ebasso/prog001_divisoes.cob --json
```
